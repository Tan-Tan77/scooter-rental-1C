# scooter-rental-1C
Автоматизация системы пункта проката электросамокатов в учебном заведении.
Конфигурцаия содержит:
1. Список студентов.
2. Список самокатов, котрые вернул или забрал студент.
3. Возможность покупать новые и учитывать старые самокаты на складе.
4. Отчёты о количестве свободных самокатов, о самокатах в аренде.
